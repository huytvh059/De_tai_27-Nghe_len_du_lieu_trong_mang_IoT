# Tài liệu tham khảo & Nguồn liên kết - Đề tài 27

Dưới đây là danh sách các liên kết bắt buộc và đề xuất từ hướng dẫn đề tài nghiên cứu về "Nghe lén dữ liệu cảm biến trong mạng IoT":

## 1. Thư viện và Công cụ chính
- **Eclipse Mosquitto**: Broker MQTT mã nguồn mở, nhẹ và phổ biến nhất dùng cho môi trường IoT.
  - Link repository: [https://github.com/eclipse-mosquitto/mosquitto](https://github.com/eclipse-mosquitto/mosquitto)
- **Eclipse Paho Python Client**: Thư viện Python chính thức để kết nối và tương tác với các MQTT Broker.
  - Link repository: [https://github.com/eclipse-paho/paho.mqtt.python](https://github.com/eclipse-paho/paho.mqtt.python)
- **Mbed TLS**: Thư viện mật mã nguồn mở dùng để tích hợp các tính năng mã hóa TLS và các hàm băm bảo mật cho các thiết bị nhúng có tài nguyên hạn chế.
  - Link repository: [https://github.com/Mbed-TLS/mbedtls](https://github.com/Mbed-TLS/mbedtls)

## 2. Tài liệu học thuật liên quan
- **OWASP IoT Security Verification Standard (ISVS)**: Tiêu chuẩn xác thực bảo mật IoT giúp thiết lập các quy tắc bảo mật dữ liệu ở mức truyền tải và lưu trữ.
  - Link repository: [https://github.com/OWASP/IoT-Security-Verification-Standard-ISVS](https://github.com/OWASP/IoT-Security-Verification-Standard-ISVS)
- **RFC 2104 - HMAC**: Tiêu chuẩn kỹ thuật mô tả cơ chế mã xác thực thông điệp dựa trên khóa băm (Keyed-Hashing for Message Authentication).
  - Link tài liệu: [https://datatracker.ietf.org/doc/html/rfc2104](https://datatracker.ietf.org/doc/html/rfc2104)
- **NIST SP 800-38D - AES-GCM**: Đặc tả kỹ thuật của chế độ mã hóa Galois/Counter Mode (GCM) cho thuật toán mã hóa đối xứng AES, cung cấp đồng thời tính bí mật (Confidentiality) và xác thực dữ liệu (Authenticity).
  - Link tài liệu: [https://csrc.nist.gov/publications/detail/sp/800-38d/final](https://csrc.nist.gov/publications/detail/sp/800-38d/final)
